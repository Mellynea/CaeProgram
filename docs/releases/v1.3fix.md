# CaeDuex v1.3fix

Corrective release for the native-memory exhaustion reported in [issue #2](https://github.com/Mellynea/CaeProgram/issues/2).

- Reuse native drawing buffers on Minecraft 1.20.1 and 1.20.4 instead of allocating a new backing buffer for every HUD primitive. Keep nested and unfinished batches separate, and bound unfinished allocations.
- Release the independently allocated buffers used by legacy preview batches. Preserve outstanding mesh ownership and support retrying cleanup safely.
- Release building-preview meshes and GPU resources when creation or upload fails, and close shaders when compilation or uniform initialization fails.
- Reject building files whose dimensions overflow the size calculation. Valid building files retain their existing format and save/load behavior.

Install the JAR for your exact Minecraft version and loader, replacing the previous CaeDuex JAR in the instance's `mods` directory. Existing configuration and building files remain compatible.

This release retains the v1.3 feature set, including ordinary application projection. The separate v1.4 development features are not included.

Validation includes native-buffer allocation/lifetime checks, preview/shader fault injection, real NBT malformed-input and round-trip checks, and independent target builds. These checks do not claim exhaustive gameplay or third-party mod compatibility testing. No flashing tests were performed. The reporter's ZIP attachment was not downloaded or executed.
